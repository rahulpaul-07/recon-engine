# Sample datasets

Seven batches, each generated by `src/generate_data.py` with different flags.
Every one includes a `ground_truth.csv` answer key that the reconciliation
engine never reads — it exists so accuracy can be measured rather than claimed.

Amounts are integer paise throughout: `45000` means ₹450.00.

| Folder | Generated with | Character |
|---|---|---|
| `01-reference` | `--seed 42 --orders 120` | The batch every figure in the README refers to. 90.8% resolved, 100% classification accuracy, 13 exceptions. |
| `02-small` | `--seed 7 --orders 60` | Just above the track's 50-record floor. 85.0% resolved — a smaller batch has proportionally more unsettled tail. |
| `03-large` | `--seed 3 --orders 1000` | 98.7% resolved. Defect counts are fixed while orders scale, so the defect rate falls as the batch grows. |
| `04-ambiguous` | `--seed 42 --orders 120 --ambiguous 3` | Three pairs of settlements sharing an amount and payout window, references stripped. Exercises optimal assignment. |
| `05-compound` | `--seed 11 --orders 200 --compound --defect-scale 3` | Several defects on one record. Classification drops to 97.2% — the taxonomy allows one label per record. |
| `06-dense` | `--seed 5 --orders 150 --defect-scale 4` | Four times the defect rate, but non-interacting. Resolution falls to 76.5%; **classification stays at 100%**. |
| `07-malformed` | hand-edited | `ledger.csv` has `order_reference` where `order_id` is expected. For exercising error handling. |

## The two rates are different things

`06-dense` is the pair worth understanding. Resolution falls to 76.5% because
more records are defective and therefore need a human. Classification stays at
100% because each record is still correctly identified.

A falling resolution rate means more work for an analyst. A falling
classification rate means the engine is *wrong*. Only the second is a defect in
the system, and conflating them is the easiest way to misread this project.

## Files in each batch

```
ledger.csv        merchant order book — gross amounts, no fees
gateway.csv       payments, refunds, chargebacks — signed, with fees
settlements.csv   payout report — links gateway rows to bank credits
bank.csv          statement lines — one credit per payout, messy narration
ground_truth.csv  answer key — never read by the engine
```

## Reproducing any of them

```bash
python3 src/generate_data.py --seed 42 --orders 120 --out data
python3 src/evaluate.py --data data
```

Generation is deterministic under a seed, so these directories can be deleted
and rebuilt exactly.
